# Historical generated diagrams

The dated bundles in this directory were generated before the 0.11 structural
review. Their HTML, candidate specifications and delivery receipts are historical
artifacts, not the current architecture contract or executable source.

A generated bundle stays local: `.archify/` is ignored, so a new diagram is
read in the browser rather than committed. The bundles kept here are the ones a
review already cited.

Use [the architecture contract](../docs/ARCHITECTURE.md) for current behavior and
[the full source review](../docs/REVIEW-2026-11-14.md) for review scope and evidence.
