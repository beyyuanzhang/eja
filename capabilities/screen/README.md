# 屏幕感知

在 macOS 14 或更新版本上，使用支持图像输入的模型和本仓库构建的 eja 宿主。

```sh
bash capabilities/screen/install.sh
```

脚本向当前 eja 数据目录安装一条 `exec` 能力，可传入数据目录路径覆盖。安装后在设置的「能力」页开关或移除。

eja 通过同一个 `cap_screen` 工具观察和操作界面。

| 请求 | 结果 |
| --- | --- |
| `{}` | 列出当前显示器和窗口 |
| `{"source":"window:123"}` | 返回一帧 JPEG，沿用模型的通用图像入口 |
| `{"source":"window:123","inspect":true}` | 读取窗口公开的辅助功能控件、文字和值，返回可用于点击的中心坐标 |
| `{"source":"display:1","action":{"type":"click","at":{"x":0.35,"y":0.6}},"capture":true}` | 点击后查看同一个显示器的新画面 |

鼠标操作支持移动、点击、右键、双击、拖拽和滚动。坐标相对于所选画面左上角，范围为 0 到 1。窗口被挡住时可从显示器画面操作。按键（如 `cmd+a`）和文字输入发给当前焦点，指定窗口时会校验焦点。

截图需要 macOS 的「屏幕与系统音频录制」权限。读取控件和发送输入需要「辅助功能」权限。重新运行安装脚本可升级现有能力，原开关状态会保留。
